# AI Skill Manager v0.2.0

Manage skill folders across local AI coding tools on Windows x64 and Ubuntu 22.04 x64.

## Changes

- Preserve scan comparisons, focus and selections when changing the saved theme; prevent operations on stale results after a failed post-operation refresh.
- Add indexed selection lookups and one-pass action counts.
- Replace harness tabs with adaptive sidebar/selector navigation, fit the comparison panes to the window, and make list/details scroll independently.
- Add accessible status-count filters, filtered/hidden selection controls, Ctrl+F search and reduced-motion support.
- Report real scan stage counts and cached source reuse.
- Explain complete destination replacement in difference details and allow copying literal source, destination and difference paths.
- Summarize successful and failed operation results separately from selections skipped during preparation.

## Packages and verification

Choose the Windows x64 NSIS installer or Ubuntu amd64 deb. Verify against SHA256SUMS.txt before installing. SOURCE_COMMIT.txt identifies the packaged source. Packages are unsigned.

On Ubuntu, from the download directory:

```bash
sha256sum --ignore-missing -c SHA256SUMS.txt
sudo apt install './AI.Skill.Manager_0.2.0_amd64.deb'
```

GitHub may normalize spaces in uploaded asset names; use the downloaded filename if it differs.
