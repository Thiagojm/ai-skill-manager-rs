## Packages and verification

Choose the Windows x64 NSIS installer or Ubuntu amd64 deb. Verify against SHA256SUMS.txt before installing. SOURCE_COMMIT.txt identifies the packaged source. Packages are unsigned.

On Ubuntu, from the download directory:

```bash
sha256sum --ignore-missing -c SHA256SUMS.txt
sudo apt install './AI.Skill.Manager_0.1.1_amd64.deb'
```

GitHub may normalize spaces in uploaded asset names; use the downloaded filename if it differs.
